# Задача 25: Статистика оценок группы

**Студент:** Сидоркевич А.В.

## Постановка задачи
Реализовать функции для расчета статистики оценок группы (mean, median, passed_count) и покрыть их двумя видами тестов: классическими юнит-тестами и BDD-сценариями.

## Структура проекта
- main.py — модуль с реализацией функций.
- test_main.py — юнит-тесты (pytest).
- features/stats.feature — BDD-сценарии на языке Gherkin.
- test_bdd.py — шаги для привязки BDD-сценариев к коду (Step Definitions).
