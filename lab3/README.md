# Задача 25: Бронирование столиков

**Студент:** Сидоркевич Александра

## Постановка задачи

Написать юнит-тесты и измерить покрытие кода для модуля `main.py`, реализующего логику бронирования столиков. 
Модуль содержит функции:
- `add_table` — добавление столика;
- `book` — бронирование столика (с учетом времени, числа гостей и занятости);
- `cancel` — отмена брони;
- `free_tables` — получение списка свободных столиков на слот.

Необходимо добиться покрытия кода тестами не менее 90%.

## Структура репозитория

- `main.py` — тестируемый модуль с функциями.
- `test_main.py` — файл с юнит-тестами (pytest).
- `requirements.txt` — список зависимостей для тестирования.
