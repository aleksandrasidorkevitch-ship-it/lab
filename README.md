# Задача 25: Система бронирования столиков

**Студент:** Сидоркевич А.В

## Постановка задачи

Столик: номер, вместимость. Бронь: имя гостя, время, число гостей.
Операции: забронировать (подобрать столик ≥ числа гостей), отменить бронь,
список свободных столиков на слот.

## Файлы

- `structural.py` — решение в структурном стиле (данные и функции отдельно).
- `oop.py` — решение в ООП-стиле (классы Table, Booking, Restaurant).
